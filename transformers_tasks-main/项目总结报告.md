### A. UIE 信息抽取（权重已下好，直接训练即可）

**数据**：项目内已有，无需再下。  
**模型页**：https://huggingface.co/Pky/uie-base-zh （镜像：https://hf-mirror.com/Pky/uie-base-zh ）

```powershell
$env:HF_ENDPOINT="https://hf-mirror.com"
$env:PYTHONUTF8="1"
$env:PYTHONIOENCODING="utf-8"
conda activate graph_test
cd "c:\Users\windows\Desktop\开学测试\transformers_tasks-main\UIE"

python train.py `
  --pretrained_model "uie-base-zh" `
  --save_dir "checkpoints/DuIE" `
  --train_path "data/DuIE/train.txt" `
  --dev_path "data/DuIE/dev.txt" `
  --img_log_dir "logs/" `
  --img_log_name "UIE-Base" `
  --batch_size 8 `
  --max_seq_len 256 `
  --learning_rate 5e-5 `
  --num_train_epochs 5 `
  --logging_steps 10 `
  --valid_steps 50 `
  --device "cuda:0"
```

若 `torch.load` 报安全/权重错误，在 `train.py` 中改为：

```python
model = torch.load(..., weights_only=False)  # 旧版整模 pickle
```

推理：`python inference.py`（按该目录 readme 改路径）。

### B. 生成式问答 T5（`answer_generation/`）

**数据**：本地已有 `data/DuReaderQG/`（约 1.4 万条）。  
**需下载模型**：

- HuggingFace：https://huggingface.co/uer/t5-base-chinese-cluecorpussmall  
- 镜像：https://hf-mirror.com/uer/t5-base-chinese-cluecorpussmall  

```powershell
$env:HF_ENDPOINT="https://hf-mirror.com"
$env:PYTHONUTF8="1"
conda activate graph_test
# 可选：先单独下载
huggingface-cli download uer/t5-base-chinese-cluecorpussmall --local-dir "D:\models\t5-base-chinese"

cd "c:\Users\windows\Desktop\开学测试\transformers_tasks-main\answer_generation"
python train.py `
  --pretrained_model "uer/t5-base-chinese-cluecorpussmall" `
  --save_dir "checkpoints/DuReaderQG" `
  --train_path "data/DuReaderQG/train.json" `
  --dev_path "data/DuReaderQG/dev.json" `
  --img_log_dir "logs/DuReaderQG" `
  --img_log_name "T5-Base-Chinese" `
  --batch_size 8 `
  --max_source_seq_len 256 `
  --max_target_seq_len 32 `
  --learning_rate 5e-5 `
  --num_train_epochs 3 `
  --logging_steps 20 `
  --valid_steps 200 `
  --device "cuda:0"
```

> 8GB 显存建议 `batch_size=4~8`；完整 50 epoch 很久，演示用 3 epoch 即可。

## 五、建议你本地注意

1. **C 盘空间**：中间 checkpoint 极占空间，训练时只保留 `model_best`，或定期删 `model_*`。  
2. **GPU 占用**：同时只跑一个训练任务。  
3. **PowerShell**：用上面带 `` ` `` 续行的命令；或写成一行。  
4. 大模型优先用 `huggingface-cli download ... --local-dir` 下到 `D:\models\`，再在脚本里传本地路径。
